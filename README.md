# فروشگاه انتخاب من — راه‌اندازی ساده

خبر خوب: رمز عبور مدیر (`PEYMAN 9389208502`) از قبل هش شده و توکن امنیتی هم از قبل ساخته شده.
دیگر نیازی به نصب Node.js روی سیستم خودتان یا اجرای هیچ دستوری نیست — فقط این پروژه را روی یک هاست آنلاین بگذارید.

## ساده‌ترین روش: انتشار روی Render.com (رایگان)

### مرحله ۱ — گذاشتن پروژه در GitHub
1. وارد github.com شوید و یک حساب رایگان بسازید (اگر ندارید).
2. روی «+» بالای صفحه بزنید → **New repository**. یک اسم بدهید، مثلاً `entekhab-store`، و **Create repository** را بزنید.
3. در صفحه‌ی مخزن تازه‌ساز، روی لینک «uploading an existing file» بزنید.
4. تمام فایل‌ها و پوشه‌های داخل این zip را بکشید و رها کنید (drag & drop) — **از جمله فایل `.env.example`**.
5. پایین صفحه دکمه‌ی **Commit changes** را بزنید.

### مرحله ۲ — ساخت فایل .env در گیت‌هاب
1. داخل مخزن، روی فایل `.env.example` کلیک کنید.
2. روی آیکون مداد (ویرایش) بزنید.
3. بالای صفحه، نام فایل را از `.env.example` به `.env` تغییر دهید.
4. **Commit changes** را بزنید. (محتوای فایل را دست نزنید — آماده است.)

### مرحله ۳ — ساخت سرویس در Render
1. وارد render.com شوید و با حساب GitHub خود ثبت‌نام کنید.
2. روی **New +** → **Web Service** بزنید.
3. مخزن `entekhab-store` را انتخاب و **Connect** کنید.
4. تنظیمات را این‌طور بگذارید:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** Free
5. روی **Create Web Service** بزنید.

بعد از چند دقیقه، Render یک لینک عمومی به شما می‌دهد (چیزی شبیه `https://entekhab-store.onrender.com`) — همین لینک را می‌توانید به مشتری‌ها بدهید.
